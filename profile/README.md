# CactusFire

A Spanish Discord bot for fun, community and moderation, configured from a web dashboard.

**[Website](https://cactusfire.xyz)** · **[Add to Discord](https://discord.com/oauth2/authorize?client_id=543567770579894272&permissions=8&scope=bot%20applications.commands)** · **[Discord page](https://discord.com/discovery/applications/543567770579894272)**

## What it does

- Moderation and automod
- Giveaways, welcome messages and tickets
- Twitch and YouTube notifications
- Everything configurable from the dashboard at [cactusfire.xyz](https://cactusfire.xyz)
- **CactusFire Games**: ten multiplayer party games played inside Discord voice channels, as a Discord Activity
